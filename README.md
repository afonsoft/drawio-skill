# Agent Skills Collection

A curated collection of specialized skills and hooks for AI agents.

[![skills.sh](https://skills.sh/b/afonsoft/skills)](https://skills.sh/afonsoft/skills)

## Overview

This repository distributes agent skills following the Agent Skills specification (agentskills.io). It provides specialized guidance and tools to enhance the capabilities of AI agents across various platforms.

## Available Skills

- **code-review-and-quality**: Multi-axis code review for correctness and quality.
- **building-mcp-servers**: Guide for creating high-quality MCP servers.
- **create-agent-harness**: Bootstrap production-ready agent harnesses.
- **observability-and-instrumentation**: Instrumenting code for production visibility.
- **sonarqube-review**: Automated fixing of SonarQube code quality issues.
- **drawio-architecture**: Architecture diagram authoring with MCP integration.

## Installation

### via skills.sh (recommended)
```bash
npx skills add afonsoft/skills
```

### via Agent Skills (agentskills.io)
```bash
npx agent-skills add afonsoft/skills
```

### via SkillsMP
```bash
npx skillsmp add afonsoft/skills
```
