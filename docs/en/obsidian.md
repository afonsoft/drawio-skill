# Obsidian
A single skill for everything Obsidian: the CLI, Bases (.base files), and Obsidian Flavored Markdown — merged from the former `obsidian-cli`, `obsidian-bases`, and `obsidian-markdown` skills.
## 🎯 Purpose
Interact with Obsidian vaults from the command line, build database-like Bases over notes, and author Obsidian-specific Markdown (wikilinks, embeds, callouts, properties) — plus develop and debug plugins/themes.
## 🛠️ What it covers
1. **CLI**: read/create/search/manage notes, tasks, and properties; reload plugins, run JavaScript, capture errors, take screenshots, inspect the DOM.
2. **Bases**: `.base` files with filters, formulas, and table/cards/list/map views.
3. **Markdown**: wikilinks, embeds, callouts, properties/frontmatter, highlights, Mermaid, math.
## 🚀 Usage
Use when the task touches an Obsidian vault — CLI operations, Bases, OFM authoring, or plugin/theme development. For non-Obsidian Markdown, this skill does not apply.
