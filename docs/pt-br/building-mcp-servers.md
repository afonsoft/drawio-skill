# Construindo Servidores MCP
Um guia abrangente para desenvolver servidores do Model Context Protocol (MCP) que capacitam LLMs a interagir com APIs e serviços externos.

## 🎯 Objetivo
Padronizar a criação de servidores MCP em diferentes linguagens (TypeScript, Python, C#) para garantir que sejam the discoveráveis, eficientes e seguros.

## 🛠️ Como Funciona
A skill guia o desenvolvedor através de um ciclo de vida de 4 fases:
1. **Pesquisa e Planejamento**: Design de ferramentas baseado na cobertura de API e a discoverabilidade.
2. **Implementação**: Uso de SDKs (TypeScript, FastMCP, .NET) para construir ferramentas, recursos e prompts.
3. **Revisão e Teste**: Validação com o MCP Inspector e garantia de tipagem.
4. **Avaliação**: Criação de um conjunto de 10 pares de perguntas e respostas complexas para verificar a eficácia do servidor no mundo real.

## 🚀 Uso
Use esta skill quando precisar dar um "novo superpoder" ao agente — como conectá-lo a um banco de dados proprietário, uma API legada ou uma ferramenta interna customizada.

## 🔗 Correlação
- **Caminho Avançado**: Esta é a extensão "power-user" do harness. Enquanto o `create-agent-harness` configura o agente, o `building-mcp-servers` fornece novas capacidades.
- **Integração**: O servidor resultante pode ser configurado no `TOOLS.md` de um harness criado pelo `create-agent-harness`.
