# Obsidian
Uma única skill para tudo no Obsidian: a CLI, Bases (arquivos `.base`) e Obsidian Flavored Markdown — fundida das antigas skills `obsidian-cli`, `obsidian-bases` e `obsidian-markdown`.
## 🎯 Propósito
Interagir com cofres Obsidian via linha de comando, construir Bases semelhantes a banco de dados sobre notas e escrever Markdown específico do Obsidian (wikilinks, embeds, callouts, propriedades) — além de desenvolver e depurar plugins/themes.
## 🛠️ O que cobre
1. **CLI**: ler/criar/pesquisar/gerenciar notas, tarefas e propriedades; recarregar plugins, rodar JavaScript, capturar erros, tirar screenshots, inspecionar o DOM.
2. **Bases**: arquivos `.base` com filtros, fórmulas e views table/cards/list/map.
3. **Markdown**: wikilinks, embeds, callouts, propriedades/frontmatter, destaques, Mermaid, math.
## 🚀 Uso
Use quando a tarefa envolve um cofre Obsidian — operações via CLI, Bases, escrita OFM ou desenvolvimento de plugin/theme. Para Markdown fora do Obsidian, esta skill não se aplica.
